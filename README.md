# My first mipmap game
My first ever project for Hack Club Mipmap: A very, **very** simple game written in SFML. 

## Build
If for some reason you want to try the game out it's made from a CMake SFML template, so just run 
```
cmake -B build
cmake --build build 
```
and you're free to go!

## AI
No agents were ~~harmed~~ used in the making of this project. Every single line of code was written (or understood, then copied and pasted) by me.
